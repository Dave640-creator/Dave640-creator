     ║   🐍 SNAKE ANIMATION — ONE-TIME SETUP (takes ~5 minutes)
     ╠══════════════════════════════════════════════════════════════════
     ║
     ║  STEP 1 — Make sure your profile repo exists:
     ║    Go to github.com/new and create a repo named exactly:
     ║    Dave640-creator   (same as your username)
     ║    ✅ Check "Add a README file"   ✅ Set to Public
     ║
     ║  STEP 2 — Create this file inside that repo:
     ║    Path:  .github/workflows/snake.yml
     ║    Paste this exact content:
     ║
     ║  ─────────────────────────────────────────────
     ║  name: Generate Snake
     ║  on:
     ║    schedule:
     ║      - cron: "0 0 * * *"
     ║    workflow_dispatch:
     ║  jobs:
     ║    generate:
     ║      runs-on: ubuntu-latest
     ║      steps:
     ║        - uses: actions/checkout@v3
     ║        - uses: Platane/snk@v3
     ║          with:
     ║            github_user_name: ${{ github.repository_owner }}
     ║            outputs: |
     ║              dist/github-contribution-grid-snake.svg
     ║              dist/github-contribution-grid-snake-dark.svg?palette=github-dark
     ║        - uses: crazy-max/ghaction-github-pages@v3
     ║          with:
     ║            target_branch: output
     ║            build_dir: dist
     ║          env:
     ║            GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
     ║  ─────────────────────────────────────────────
     ║
     ║  STEP 3 — Run it manually once:
     ║    Go to your repo → Actions tab → "Generate Snake" → Run workflow
     ║    After ~1 minute the snake SVG will appear and auto-update daily ✅
     ║
     ╚══════════════════════════════════════════════════════════════════ -->
